# 段落审查规格(逐段过筛——八维度诊断框架)

> 一章、一段地筛:对任意一个段落,按八维度逐项拆解诊断——场景/事物/逻辑/人物/表达/写作技法/句式/对白。与 23-prose-expression(文笔标准,给"好"的定义)配合使用:本规格给**审查框架**(怎么查一段),23 号给**评判标准**(查到什么算好)。适用于任何题材、任何章节。**类型中立,零项目词**。

## 一、为什么逐段筛

- 章节级审查会漏掉段级问题:一段内的时序矛盾/视角跳切/逻辑断裂/句式失控,只有逐段看才现形
- 逐段筛=地毯式:每段都过一遍八个维度,问题在段落层面就拦截,不留给整章
- 配合流程:初稿 → 23号七维度打磨(文笔) → **本规格逐段过筛**(结构/逻辑/技法) → 整章复查

## 二、八维度框架(对每段逐项问)

### ① 场景
- 这一段落在什么场景?时间/地点/空间层次?
- 场景是"远景/中景/近景"哪一层?镜头怎么推进/切换?
- 场景与前后段落是否衔接(同场景延续/转场清晰)?
- **自检**:读者能画出这段的空间吗?不能=场景模糊

### ② 事物
- 写了哪些事物/物件?(自然物/人造物/道具/身体/声音气味)
- 每个事物是否"有用"?(推动剧情/塑造人物/营造氛围/埋设伏笔——无用的删)
- 事物的选择是否克制?(堆砌=失焦)
- **自检**:有没有"存在但没意义"的事物?有=删或让它有意义

### ③ 逻辑
- 段内时序通吗?(先发生什么后发生什么,顺序是否合理)
- 因果成立吗?(A导致B,是不是硬凑?)
- 视角逻辑通吗?(这段是谁在看?他知道的、看到的是否超出他的权限?)
- 信息真实性:世界观内的物理/规则是否自洽?(山高先雪/城低后霜这类温差逻辑)
- **自检**:把这段当"事实陈述"读一遍,有没有读者会"咦?"的地方

### ④ 人物
- 这段写了谁?人物此刻的状态(位置/衣着/伤势/神志/手持)?
- 视角人物是谁?这段是否保持他的视角(限知不越权)?
- 人物动作/反应是否符合他的身份/性格/前文?
- 无人物出场时:谁在"看"?是上帝视角还是镜头?
- **自检**:人物在这段里的行为,换一个人是否也成立?成立=人物没立住

### ⑤ 表达(这段要传达什么)
- 表层信息是什么?(发生了什么/看到了什么)
- 深层是什么?(主题/情绪/伏笔/暗示)
- 情绪基调是什么?(冷/暖/压/撕/暗流)
- 这段在全书/本章承担什么功能?(定调/推进/转折/埋伏/留白)
- **自检**:删掉这段,全书损失什么?没损失=这段是废段

### ⑥ 写作技法
- 用了什么技法?(对比/比喻/白描/虚实/留白/镜头推进/意象钩子/反复)
- 技法是否"服务于表达"?(炫技=为技法而技法)
- 有没有形成"记忆点"的句子/意象?(读者读完全章还记得哪个?)
- 技法是否重复?(同一章内同类比喻/句式连用=疲劳)
- **自检**:这段有没有一句"值得摘抄"的话?没有=平淡;有=技法生效

### ⑦ 句式
- 句子的长短分布?(短句定调/长句铺景/长短交替的节奏)
- 句式与内容匹配吗?(重场景用短句/绵场景用长句?)
- 句首结构是否单一?(连续同样的字开头,如每句都从"他""她"起=流水账)
- 读感:朗读一遍,哪里拗口?哪里节奏断了?
- **自检**:这段话的"呼吸"对吗?读者该喘气的地方给了停顿吗?

### ⑧ 对白
- 有对白吗?没有时:这段需不需要对白?(强行加=破坏氛围)
- 有对白时:说话者符合人设吗?(腔调/用词/称呼)
- 对白推动什么?(信息/关系/情绪/行动——无效对白删)
- 对白与叙述的配比?(全是对白=剧本感;全是叙述=闷)
- **自检**:把这段对白换成别人的话,是否违和?违和=对白没立住

## 三、审查流程(先读懂→再拆解→后诊断)

1. **读懂**:先用一句话复述"这段写了什么"——复述不出来=这段意思不清,先修这个
2. **拆解**:八维度逐项过,每项给出"看到的事实"(不是评价)
3. **诊断**:每个维度判 ✅(通过)/ ⚠️(小问题,列出具体位置)/ ❌(硬伤,必须改)
4. **输出**:按下节格式给出审查表
5. **处理**:⚠️ 列清单待修;❌ 立即修;✅ 不动

## 五、段级 vs 章级分工

| 层级 | 查什么 | 用什么规格 |
|---|---|---|
| 段级(本规格) | 单段内的场景/事物/逻辑/人物/表达/技法/句式/对白 | 26 号(本规格) |
| 章级 | 全章连贯/风格统一/情绪曲线/伏笔闭环 | 23 号(文笔七维度)+ 07 检查清单 |
| 场景级(跨段) | 人物同场交互/关系温度/对话服务关系 | 22 号(场景交互) |
| 全书级 | 人物一致性/时间线/伏笔台账 | 记忆系统审计(每N章) |

**铁律**:逐段筛不能替代整章复查——段段都好不等于章好(段间衔接/节奏/情绪曲线是章级问题)。先逐段过筛,再整章复查,两层都过才算过。

## 六、完稿自查(用本规格筛过吗)

- [ ] 每一段都过了一遍八维度?(还是只看重头段?)
- [ ] 有 ⚠️/❌ 的段落都处理了吗?(还是带病进入下一章?)
- [ ] 段落之间的衔接查了吗?(段段好≠章好)
- [ ] 输出的审查表可追溯吗?(哪段哪维度什么问题,有记录)

## 七、实战示例(一个开篇段怎么跑八维度)

以一段典型的开篇定调段为例(秋景+点出主家),演示审查的完整走法。**写法通用,不绑定任何具体作品**:

> 原文示例:秋深了。桂花落尽之后,远山一夜之间落了层薄雪——山巅是初雪,城里还不见霜,只有风从山口灌进来,把街市上的旗幡吹得猎猎作响。主家的账册一天比一天厚。

### ① 场景
远景"远山+城"→ 拉近"山口的风/街市旗幡"→ 切到"主家"。空间三层次,镜头由远及近。**判定**:✅ 层次清晰

### ② 事物
薄雪/初雪/霜/风/旗幡/账册——六样。前五样是"城",最后"账册"是"主家",用一句过渡从城景滑到主家。账册点睛(商家的秋=盘点)。**判定**:✅ 克制,账册是钩子

### ③ 逻辑
"秋深了"→"桂花落尽"→"一夜落薄雪"时序递进;"山巅初雪/城里无霜"温差成立;"山口风→旗幡动"因果成立。**判定**:✅ 全通

### ④ 人物
无人物登场,只有"主家"点名。开篇段不引入人物=正确(先定世界再进人)。**判定**:✅

### ⑤ 表达
表层=秋深天冷商家忙;深层=账册=命运账簿(主家正处临界点);情绪=平静的冷。**判定**:✅ 定景+立主题+埋伏笔三合一

### ⑥ 技法
由远及近镜头/山城温差对比(高处已变低处未觉)/账册意象钩子/留白不解释。**判定**:✅ 技法老练

### ⑦ 句式
首句二字"秋深了"独立成句(定音鼓)→ 中段长句铺景 → 末句短而重收束。节奏:短→长→短。**判定**:✅ 节奏精准

### ⑧ 对白
无对白。开篇段无人可对话,强行加反而破坏定调。**判定**:✅ 不需要

### 审查结论

| 维度 | 判定 | 亮点 |
|---|---|---|
| 场景 | ✅ | 远→近三层次推进 |
| 事物 | ✅ | 六样克制,账册点睛 |
| 逻辑 | ✅ | 时序/温差/因果全通 |
| 人物 | ✅ | 无人登场,主家点名(正确) |
| 表达 | ✅ | 定景+主题+伏笔三合一 |
| 技法 | ✅ | 镜头/对比/意象钩子/留白 |
| 句式 | ✅ | 短→长→短,首句二字定调 |
| 对白 | ✅ | 无对白(正确) |

**八维全绿,保持。** 这个示例展示了:八维度不是空泛的"这段写得怎么样",而是每一维都有具体的"看到的事实"+判定理由。照这个格式,一段一段往下筛。

## 八、常见段级病(筛的时候重点找这些)

逐段过筛时,以下段级病是高发区——遇到直接标 ⚠️/❌,不要放过:

1. **时序倒挂**:段内事件顺序违反自然时序(先写结果后写原因,而原因明明该先发生)。例:写"他推开门,门吱呀一声"——先看见"推开门"的动,再听到声,顺序对;写成"门吱呀一声,他推开门"就倒了(除非故意)
2. **视角越权**:限知视角写到了人物看不到/不知道的东西(第三人称限知:写"他走进屋,没看见墙角那双眼"——"没看见"就是越权,他根本不知道有眼)。越权=读者立刻出戏
3. **信息重复**:同一段或相邻段重复交代同一信息(先说"她紧张",下句又写"她手心全是汗"——后者已是前者,只留一个)
4. **堆砌失焦**:一段塞太多事物/动作/信息,读者找不到重点。检查法:读完这段,问"这段到底在说哪件事?"答不出=堆了
5. **情绪标签**:直接贴情绪词("她悲伤地""他愤怒地")代替动作。写动作,不贴标签——"她悲伤地接过信"→"她接过信,没拆,先攥了一会儿"
6. **对白无效**:对话不推进信息/关系/情绪,纯寒暄或复述已知。检查法:删掉这句对白,剧情损失什么?没损失=删
7. **句式失节奏**:连续三句以上同长度/同开头/同结构(全短句=喘不过气;全长句=沉闷)。检查法:朗读,哪里断气哪里就是问题
8. **意象重复**:同一章内同类比喻/意象反复出现(两处"像刀一样"、三处"冷得像水")。检查法:同一比喻在章内出现第二次,换掉
9. **前后矛盾**:段内或与邻段矛盾(前文说左手,后文写右手;前文夜里,后文白天)。检查法:逐段核对时间/身体/位置的一致性
10. **废段**:整段删掉后剧情/氛围/信息零损失。检查法:问"这段存在是为了什么?"答不出=废段,删

**处理原则**:❌(硬伤)当场改;⚠️(小问题)记入审查表,本章筛完后统一修;所有修改后必须回读一遍该段确认没改出新问题。

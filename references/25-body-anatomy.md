# 人体档案规格(写人就是人——全维度身体/生活档案)

> 写人就是人:他们和真人一样,有七情六欲,有爱恨情仇,有吃喝拉撒睡,有性爱。角色卡不是"人物简介",是一份**完整的档案**——你写不出你没建档的东西。本规格给出"全维度档案清单",建档时逐项填,写作时按需调取。**类型中立**:所有条目适用于任何题材(现代/古代/科幻/奇幻/玄幻),成人向条目(性器官/性习惯)仅在作品受众为成人向时填写。零项目词:只填通用维度,不绑定任何具体作品。

## 一、建档原则

1. **档案是底稿,不是正文**:档案是"作者知道的东西",正文只写"角色被看见时"的部分——档案帮你写得准,不是让你把档案堆进正文
2. **差异化铁律**:同作品内,任意两人同一维度不许相同(两人乳房不能都"丰满",两屄不能都"粉嫩",两鸡巴不能都"粗长")——身体档案是角色的身份证,撞了=读者串人
3. **身体=命运**:疤痕/胎记/残疾/体态都是前史的痕迹,建档时写"怎么来的",写作时当伏笔(一道旧疤在关键章被看见=记忆点)
4. **成人向条目仅当涉及**:性器官/性习惯/生理期等,作品为成人向且该角色有性场景时才填——全年龄作品跳过,不留坑
5. **留白也是档案**:某维度不填=该维度"普通/不突出",这是有意的设定,不是遗漏——用"—"标注,避免写作时临时脑补

## 二、基础档案(必填,所有角色)

| 维度 | 细项 | 说明 |
|---|---|---|
| 姓名 | 全名/字/号/绰号 | 谁叫他什么=关系远近 |
| 年龄 | 生理年龄/外貌年龄/心理年龄 | 三龄可不同(驻颜/早熟/苍老),写清差在哪 |
| 性别 | 男/女/其他 | 按作品设定 |
| 出身 | 出生地/家世/阶层 | 见 02-character 地位规格 |
| 社会地位 | 出身地位×本事地位 | 双线,可冲突 |
| 修为/力量 | 境界/功法/技能/职业 | 玄幻/武侠必填 |
| 职业/身份 | 职业/官职/角色在社会的功能 | 职业决定手/衣/作息/社交圈 |
| 爱好 | 喜欢做什么/为什么 | 爱好是性格的窗口 |
| 技能 | 会什么/到什么程度 | 技能决定他能在剧情里干什么 |
| 语言 | 母语/方言/口癖/会不会外语 | 方言=地域身份,口癖=人物标签 |
| 信仰 | 信什么/忌讳什么 | 忌讳是弱点 |

## 三、建档顺序建议(角色卡怎么填)

1. 先填基础档案(二节)——骨架
2. 再填身体档案(三至五节)——逐项过,填不上的写"—"
3. 成人向作品补私密部位+性档案(三节之3、7)
4. 最后写"身体=命运"连接:选 3-5 个"有故事的维度"(疤痕/胎记/残疾/体态/手),标注其来历和伏笔用法——**这几个维度是角色立住的关键**,其余维度是背景
5. 差异化复查:同一作品内,关键维度(身形/乳房/鸡巴/屄/手/疤)与所有已建角色对比,撞了改

## 四、写作时怎么用档案

- **出场写"被看见"的部分**:档案是底稿,正文只在"被看见/被触及时"写——第一次出场写 2-3 个标志维度,别把档案抄进正文
- **性场景按档案写**:肏到谁,调谁的私密档案(屄/阴毛/松紧/反应)——禁现编,禁千人一面
- **伏笔从档案里长出来**:疤痕/胎记/旧伤/随身物,在关键剧情被再次看见=记忆点回收
- **差异化从档案里长出来**:写群像/多人场景前,先翻档案确认每人关键维度不同(配合 24 号规格)

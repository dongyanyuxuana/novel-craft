# 自愿多人性场景规格(成人向专用——仅当作品含自愿多人性场景才读)

> 处理所有**自愿性**多人场景(多人伴侣/群交/开放式关系/一主多伴夜戏)的完整规格,适用于任何题材(现代/古代/科幻/奇幻/玄幻)。**只读时机**:访谈Layer2受众尺度=成人向,且当前章节涉及"自愿多人性场景"。非自愿多人(轮奸/强奸)见 05b-sex-scenes §4;单人性场景见 05b-sex-scenes §1。此规格与 05b 配合使用,05b 的必写清单/直白词表同样适用。**类型中立**:正文用"掌场者/成员/主导者"等通用词,具体关系称谓(正妻/后宫/道侣/伴侣)按作品题材替换,不影响机制。

## 零、核心区分:自愿群交 vs 轮奸

| 维度 | 自愿群交(本规格) | 轮奸(05b §4) |
|---|---|---|
| 参与者心态 | 愿意/配合/讨好/各怀心思但非胁迫 | 被迫/崩溃/身体背叛心理 |
| 掌场者 | 掌场者(正室/主导者/核心伴侣)居中调度 | 施暴者轮流上 |
| 展示 | 自己掰开给看(自愿展示/验货) | 被强行扒开 |
| 基调 | 有秩序的亲密/宠爱/各人心思 | 酷刑感/轮换焦点 |
| 收尾 | 收尾对象有安排(关系暗示) | 无安排,纯征服 |

**写错后果**:把自愿群交写成轮奸=全员人设崩;把轮奸写成自愿群交=美化暴力。先判定自愿/非自愿再动笔。

## 一、掌场者:多人场景必须有"指挥"

- 多人性场景必有一人**居中掌场**——调度顺序/点名/评点/叫停/安排收尾
- 掌场者身份决定场景基调:掌场者(正室/核心伴侣)=有秩序的"犒劳"(掌场者指挥,其他成员侍候命);主导者掌场=征服式(主导者点名,所有人待命)
- 掌场者的指令本身就是戏:"都过来""脱了""手放下去""该你了"——每道指令都是权力与秩序的显形
- **自检**:场景里有没有一个明确的掌场者?没有=混乱的流水线,有=有秩序的群像

## 二、摆位:未轮到的人不是"看客",是被摆好的"待命者"

- 多人场景最大的错误是把未参与的人写成纯旁观者("xx在旁边看着")——他们是被**摆位**的,保持待命/展示姿态(跪成一排/趴成一排/躺在两侧)
- 摆位动作要写出来:掌场者下令,众人如何移动/跪下/保持姿态
- **执行指令的差异=人设差异**:利落解衣的/抖着解不开的/面无表情自己解的/磨蹭不肯的——同样是"脱",脱出五种人
- **自检**:每个未轮到的人此刻是什么姿态?如果只是"在旁边看",改成被摆位的待命者

## 三、展示仪式:逐个掰开/逐个验货

- 多人场景应有**展示环节**:掌场者或主导者让众人自己掰开/展示身体,逐个"验货"
- 展示是逐个点名,逐个引出差异化描写——这是多人场景集中写"身体清单"的合法时机
- 展示时写清**干湿状态**——这是信息量最大的单点:湿=期待/主动,干=抗拒/麻木/紧张,直接预示后面被肏时的反应
- 展示时的反应差异:主动往前凑的/死忍不动的/哭着的/面无表情的/抖着掰不开被帮的
- 主导者的**评点**是展示环节的钩子("紧的""这屄养得好""粉的")——评点是掌场的一部分,也埋各房心思
- **自检**:展示环节逐个写了吗?每个人的身段+性器+干湿+反应是否都不同?

## 四、身体差异化:绝不同质(不互抄)

多人场景最忌全员一个模板。每个人的差异化至少覆盖三层:

1. **身段一套**:腰/臀/胸/肩/个子/肤色——每人一个标志性特征(柳条腰/清瘦肩薄/娇小未长开/高挑肩平/单薄怯嫩)
2. **性器一套**(按人设/经历/年纪排列组合):
   - 毛:修得齐整只留一撮 / 淡稀 / 毛少 / 毛浓 / 稀稀拉拉几根
   - 颜色:偏深 / 浅 / 粉嫩 / 极浅
   - 松紧:松软但会夹 / 紧得吓人 / 小屄唇紧闭 / 死紧 / 细窄进不去
   - 湿度:已湿 / 干爽 / 干涩无一丝水光 / 未知
3. **反应一套**:主动迎/死忍掐掌心/哭带本行腔调/麻木不叫/吓哭失禁

- **自检**:任意两人换掉性器描写/反应描写,是否立刻穿帮?穿帮=没差异化

## 五、逐房临幸:每人独立戏路,禁流水线

- 每个被临幸者一套**独立戏路**:体位+主导者技巧+她的反应+互动台词,四件套全不同
- **禁"轮番同模式"**(与05b §4同款禁令):A骑乘/B后入/C托抱/D趴伏/E轻弄——体位不许重样,反应不许重样
- 戏路要与差异化配对:
  - 主动型(会伺候的)→ 骑乘/坐位,写她主动、会夹、腰自己迎
  - 死忍型(紧的)→ 后入/折叠,写指甲掐掌心、被"停"字诀磨到破功漏出一声
  - 脆弱型(娇小爱哭的)→ 托臀抱肏,写悬空没处着力、哭声带本行腔调
  - 麻木型(干涩的)→ 直接硬进,写毫无反应、像被摆弄的物件
  - 怯幼型(没长开的)→ 轻弄即止,写吓得直哭/失禁/被温柔放过
- **自检**:逐个人单独拎出来,她的体位/技巧/反应/台词是否与别人重复?

## 六、技巧控场:主导者是老手,不是蛮干

- 主导者的技巧=控场的手段,专为"吊"出反应而写:
  - **磨**:浅浅进个头又退出,在门口吊——吊到对方自己把腰送上来才给
  - **停**:顶到最深处不动,碾着磨——专治死忍型,磨到破功
  - **节奏**:慢快交替/九浅一深,节奏由主导者定,对方只能跟着走
  - **手段随人调**:对主动型按着肏/对死忍型磨到破功/对麻木型直接进/对怯幼型轻轻放过
- 技巧是戏,不是流程——每个技巧都要有"对方的反应"作为回报(送腰/破功/求饶/哭腔)
- **自检**:主导者有没有至少一种"磨/停/控"的技巧?技巧之后对方的反应写了吗?

## 七、配合者:不被肏的人也在"干活"

- 未轮到者承担**配合职能**:托腿/扶腰/揉/递帕/帮掰开/扶住颤抖的人——不是纯看着
- 配合也是人设戏:主动凑上来帮=讨好(讨好有底色:怕被弃/想争宠/本性热络);掌场者指挥配合=权力
- 配合动作穿插在被肏者的反应之间,让场景多线同时发生("她一边被肏,一边还有人在揉她/扶她")
- **自检**:每段被肏戏里,有没有至少一个配合动作?

## 八、等待者状态:肏A时,B/C/D在干什么

- 多人场景的核心张力在**等待者**——每个人被点名前的状态必须写,这是群交特有
- 等待状态差异化:从指缝里看(想看又不敢)/捂眼偷看(好奇)/望着帐顶假装无关(但身体诚实:腿间慢慢潮了)/别过头不敢看(可声音躲不开)/并紧腿又松开(被声音撩动)
- 等待者的"身体诚实"是群交特有色:姿态抗拒,身体先反应——无声的张力
- 逐个点名前的等待状态=为下一位蓄力,形成"排队临幸"的秩序感
- **自检**:肏每一个人的时候,其他等待者各自的姿态/反应都写了吗?有没有漏掉谁?

## 九、收尾与余韵

- **收尾分配**:收尾给谁/最后临幸谁——收尾对象暗示关系亲疏(掌场者/最受宠的),要有安排
- **事后温存**:搂/拍背/骂一句带着笑的/各人散场姿态(睡着了/系衣带/背过身躺下/缩墙角)——每人散场方式也是人设
- **次日余韵**:身体延续一笔——腿软/坐下轻吸气/拢垫子/夹腿小步挪。不写=白肏,写了=场景落地
- **自检**:收尾给了谁?事后每个人什么姿态?次日有没有身体余韵一笔?

## 十、对话差异化:台词按人设,不共用

- 每人台词按其背景/性格:
  - 话术型(惯会伺候/讨好型的):熟稔的媚话,但露底——眼底是讨好/怕被弃
  - 无声型(死忍的):全程不吭声,被磨到破功才漏一声,又赶紧咬住
  - 哭腔型(脆的):哭声带本行腔调(戏腔/唱词调子),求饶也是哭腔
  - 麻木型(冷的):要么不开口,开口就是一句噎人的("……不会")
  - 怯幼型(没长开的):只会小声哭/求,说不出整话
- 主导者台词含糙话+评点("松点,这么紧,爷怎么进去")——评点是掌场的一部分
- **自检**:任意两句台词换人说,是否违和?违和=差异化对了

## 十二、实战拆解:一场合格的自愿群交如何组织(完整示例)

以"久别归来的主导者 + 掌场伴侣 + 五名各怀心思的成员"为骨架,演示本规格所有要素如何落成一段连贯正文。**示例刻意不写具体题材**——称呼用"主导者/掌场伴侣/成员",落到你作品时按题材替换(见下方"题材置换表")。数字处为要素标注,写作时按此顺序组织:

**① 摆位**:主导者靠回床头,拍了拍身前的位置:"都过来。"——这话说得平,屋里却静了一下。最会来事的先起身拢了拢衣物,坐到前排;害羞的被推着过去,坐在旁边;冷着脸站在门边不动的,被掌场伴侣一句"回来"叫回,坐到最边上;最小的抱着抱枕缩在最后,也被一句"进来"叫进,挨到队伍末尾。

**② 宽衣(执行差异=人设)**:解得利落顺势挺胸的 / 闭眼抖着解、解开了也不肯松手的 / 手抖得解三次解不开、被人帮一把的 / 一言不发自己解完面无表情待好的 / 磨蹭到最后一个、脱一半就捂住胸口的。

**③ 展示仪式(逐个验货)**:主导者的目光从他们脸上扫过去,落在腿间:"掰开。"——头一个主动凑前自己掰开,早已湿了,牵出亮丝,嘴里还说着想他的话;第二个脸红到脖子根,按着腿根不动,被看着才抖着掰开,干爽紧闭,指甲掐进掌心;第三个哭着掰开,小小一个,粉嫩紧闭,声音都在抖;第四个面无表情自己掰开,干涩无一丝水光,像掰的不是自己的身子;最后一个抖成一团怎么都掰不开,掌场伴侣探身帮他分开,他呜地一声掉眼泪,夹紧腿又想合上。

**④ 评点**:紧的 / 这屄养得好 / 粉的 / 没长开呢——评点逐个落在展示之间,也是掌场的一部分。

**⑤ 掌场伴侣主体戏(前戏完整)**:主导者这才回头,把掌场伴侣按回床上。先低头含住乳尖打转地舔,一手揉另一边;一路往下亲,亲过肚皮、亲过痕迹,最后分开腿埋下头——掌场伴侣啊了一声,腿夹紧他的头,又被旁边坐着的帮了把手按住掰开。他抓床单的手背青筋都起来,潮红从脖子烧到胸口,腰弓起来又被按住,僵了好一会儿,才整个人瘫下去,像被抽走了骨头。

**⑥ 技巧控场(磨/停)**:进去前先用指腹探了探,早湿透了——却偏不急,浅浅进个头又退出来。她嗯了一声去够他的腰;他不给,就在门口磨,磨得她受不了自己把腰送上来,他才整根顶进最深处,她的尾音都劈了。他这才笑,压着她慢慢地肏,磨得极深,又拔出来只留龟头,再整根送进去——她被这一套磨得又骂又求,白天那个端庄的样子早没了影。

**⑦ 配合者**:待在床边最近的成员一手托着她的腿,一手揉着她屄珠,嘴上还问"可舒坦?"——她喘着气骂"小蹄子",却没让她停。

**⑧ 等待者状态(肏A时BCD在干什么)**:害羞的从指缝里看,脸上红得能滴血,没人叫她动就不敢动,指甲掐进掌心;娇小的把脸埋进枕头又偷露一只眼;冷脸的直直坐着望天花板,腿间却慢慢潮了一点,自己都没察觉;最小的缩在墙角闭着眼,可那一声一声全往耳朵里钻,他并紧腿又松开,脸烧得通红。

**⑨ 逐一临幸(每人独立戏路,禁流水线)**:
- 主动型→骑乘:自己扶着坐下去,看着松软却一进去就夹住,他嘶了一声拍她臀"倒学会夹了?"她腰扭得像水蛇,一上一下地磨,嘴里说着就惦记他这一根——话是媚的,眼底却是怕被弃的讨好。
- 死忍型→后入:清瘦的背弓起来,腰塌臀翘,干得紧涩。他不急,蘸了上一位留下的水抹在穴口,才慢慢顶。她咬唇不吭,手指掐进床单——紧得他进到一半就被咬住,拍她臀"松点,这么紧怎么进去",她抖着从牙缝挤"松……松不了"。他就停在她穴口一寸一寸地磨,磨到她腰腿发软,自己塌腰把臀送上来,他才整根顶进,她啊了一声又咬住,可那一声已漏了出来——他专往她最受不住的地方撞,她死忍,掐出白印,最后从鼻子里漏出闷哼,又咬住嘴唇,眼泪顺着脸颊滑。旁边待命的看得眼热,凑过来替她揉着屄珠,她呜了一声,腿根抖得厉害,再也忍不住,终于叫出了声。
- 脆弱型→托臀抱肏:个子小,被一把抱起来托着,两条腿挂在他手臂上,就着站姿顶进去——她啊地哭出来,哭声带着本行腔调,一颤一颤的:"轻些……疼……"她悬在半空没处着力,只能搂紧他脖子,两条细腿夹着他的腰,哭得一抽一抽。放下让她趴着从后面进去,哭得更凶,腔调还是没变。掌场伴侣在旁摇头笑:"小哭包,连哭都带着调子。"又拍她背:"乖,不哭,他疼你呢。"
- 麻木型→硬进:冷着脸,干涩,进得艰难,他吐了口唾沫抹在穴口才挤进去。她一动不动,脸埋进枕头,连哼都不哼,像被摆弄的木偶。他一边肏一边看她,忽然叹口气:"你就不会叫一声?"闷闷的声音从枕头里传出:"……不会。"他反倒笑了,按着她的腰一下一下肏。旁边有人嘀咕"木头似的,肏着也没滋味",她趴在枕头里,睫毛颤了一下,又不动了。
- 怯幼型→轻弄:最小的抖成一团,两手捂着自己怎么也不肯松。他没狠折腾,先放床上亲了亲额头:"不怕,我不动你。"她还在抖,他揉了揉她头发,让她趴过去只轻轻探了探——细窄,才进个头她就吓得直哭,他就不再动,抽出来把她抱到墙角用被子裹好:"睡吧,吓着你了。"她缩在被子里半天没敢睁眼——可谁都看见,她身下那片不知什么时候湿了,洇在床单上,她自己都不知道是什么时候吓出来的。

**⑩ 收尾分配 + 事后温存 + 次日余韵**:到最后把掌场伴侣搂在怀里,左边一个右边一个,叹气"还是家里好"。掌场伴侣在他怀里拱了拱,骂一句"死鬼",带着笑,软得不像话。各人散场:娇小的早蜷在床尾睡着了,死忍的捡件衣物披上低头系带子,冷脸的背过身躺下,最小的缩墙角裹着被子睡着了头一点一点。灯吹熄,黑暗里几个人的呼吸慢慢匀下来。次日掌场伴侣坐下时轻轻吸了口气,把身下的垫子拢了拢才坐稳当——这一笔,让前一夜落到实处。

## 十三、题材置换表(同一骨架落到不同题材)

规格机制不变,只换称谓/道具/指令语境:
